# Quickstart
Node >=22.13; npm ci; copiar .env.example a .env; APP_PASSWORD >=12 caracteres.
npm run dev; http://localhost:5173.
Recorrido: Abrir a 390 px, autenticar, recargar y cerrar sesión.
npm run check; npm test; npm run build; npm run test:e2e.
Esperado: persistencia, privacidad y pantalla de 390 px sin desbordamiento.
